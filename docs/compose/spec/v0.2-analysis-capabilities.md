# dsh-analyze v0.1.2 analysis capabilities

## Report

**What was built** — CLI + tools `values` / `sample` / `join`; `transform_agg`
whitelist `mutate` and time-period `groupBy` (day|week|month, UTC, parseFailCount).
Version 0.1.2 with capabilities tokens `values,sample,join`. Neutral wording;
session root helper uses `dsh-analyze-sessions` (no product-specific names).

**Verification** — `cargo test --release -p dsh-analyze`: 9 passed.
`node --test` analysis-tools + analysis-policy: 30 passed.
Real binary e2e: ingest → values → sample (deterministic) → join →
agg mutate+time via spec file; invalid expr/period/mutate shape → exit 2.

## [S1] Problem

Agent sessions need richer local analysis without dumping tables into context:
value distributions, deterministic samples, equi-joins, derived columns, and
time-bucketed group-bys — still as small JSON tool results over on-disk CSV.

## [S2] Design

### S2.1 Contract freeze

Public CLI/tool protocol is documented in `docs/interface.md` (v0.1.2).
Binary version string and `capabilities` bump to `0.1.2` with tokens:
`ingest,head,schema,describe,agg,list,export,rm,values,sample,join`.

### S2.2 `values`

CLI `values --dataset-id --column [--limit]`. Returns `nunique`, `nullCount`,
and `top` of `{value,count,ratio}` (default top 20, limit 1..100). Nulls
excluded from top. Tool name `dataset_values`.

### S2.3 `sample`

CLI `sample --dataset-id [--n] [--seed] [--stratify-by]`. Deterministic
SplitMix64; default seed 42. Output same shape as `head` plus `sampling`
metadata. Tool name `dataset_sample`. n clamped 1..20.

### S2.4 `join`

CLI `join --left --right --on a,b [--how inner|left] [--out label]`.
Always persists a new dataset (`producedBy=join`, parent=left). Returns ids
and counts only. Null keys never match. Result rows > max rows → `analysis/limit`.
Tool name `dataset_join`.

### S2.5 `mutate` in `agg`

Optional `mutate: [{as,expr}]` in agg spec. Whitelist grammar: identifiers,
numbers, `+ - * /`, parentheses, unary minus. Applied after filter, before
groupBy. Illegal expr → `analysis/invalid-args` with no partial write.

### S2.6 Time-period `groupBy`

`groupBy` entries may be `{"dateColumn","period": day|week|month}`. Output
column `"<dateColumn>_<period>"`. Parse `YYYY-MM-DD` and
`YYYY-MM-DDTHH:MM:SS` (optional Z / offset). Unparseable non-null → null
bucket + `parseFailCount`. Week = Monday of UTC ISO week.

### S2.7 TS plugin

`ANALYSIS_TOOL_NAMES` extended; `validateAggSpec` checks mutate expressions;
tool descriptions stay small-JSON oriented. Neutral module wording only.
